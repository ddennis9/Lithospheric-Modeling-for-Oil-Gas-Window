This project is a part of my high school Scientific Technological Independent Research class. The end goal of this project isn't fully clear yet. 
My mentor and I haven't yet decided whether we want this project to be on the theoretical side of things or if we want it to be applicable to the real world.
The basic idea of this project is modeling a 1D column of some sedimentary basin, and then simulating natural heat flow over some time frame to locate the oil and natural gas windows, respectively.
